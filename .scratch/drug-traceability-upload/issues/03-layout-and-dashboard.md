# 03 — 布局与首页仪表盘

**What to build:** Bootstrap 5 全局布局（左侧可折叠菜单）和首页四个统计卡片。完成后可以登录看到布局和实时统计数据。

**Blocked by:** 01 — 基础与登录

**Status:** ready-for-agent

- [ ] 全局布局：左侧菜单栏 + 右侧内容区
- [ ] 菜单默认收起（仅 SVG 图标），展开时显示图标+文字
- [ ] 菜单项：首页、单据上传（含子菜单：上传任务/已上传/失败记录）、手动上传
- [ ] 菜单收起/展开切换按钮（平滑过渡动画）
- [ ] 响应式布局：移动端菜单自动隐藏
- [ ] 首页统计卡片：今日上传总数、成功数、失败数、待处理数
  - [ ] 成功/失败/总数从 SQLite `upload_logs` 查询（当天）
  - [ ] 待处理从 SQL Server 查询（调用 `config/sql.php` 逻辑，返回行数）
- [ ] 四个卡片水平排列，颜色区分（蓝/绿/红/黄），加载时显示骨架屏或数字动画
- [ ] 登录后默认进入首页仪表盘
