# 04 — 上传任务页面

**What to build:** 上传任务子页面的完整 CRUD + 批量操作功能。完成后可以对上传任务进行查看、编辑、删除、重传和批量操作。

**Blocked by:** 02 — 核心上传管线, 03 — 布局与首页仪表盘

**Status:** ready-for-agent

- [ ] 表格展示：日期、单号、往来单位名称、追溯码、任务状态
- [ ] 任务状态颜色标签：等待上传(灰)、上传中(蓝)、已上传(绿)、任务失败(红)、部分上传成功(黄)
- [ ] 每个列头有筛选功能（日期范围、状态下拉、文本输入）
- [ ] 全局搜索框支持全文模糊搜索
- [ ] 顶部刷新按钮：重新从 SQLite 加载最新状态
- [ ] 分页（底部页码），每页 20 条
- [ ] 编辑按钮 → 弹窗，可修改日期、单号、往来单位、追溯码，保存后更新 SQLite
- [ ] 删除按钮 → 确认框，删除单条记录
- [ ] 手动重传按钮 → 调用 UploadService 重新上传，成功后刷新状态
- [ ] 全选复选框（表头）+ 每行复选框
- [ ] 批量删除按钮：选中项批量删除 + 确认框
- [ ] 批量重传按钮：选中项批量调用 UploadService
- [ ] 所有操作通过 AJAX API 端点完成，不刷新页面
- [ ] API 端点：`GET/PUT/DELETE /api/tasks`、`POST /api/tasks/:id/retry`、`POST /api/tasks/batch-delete`、`POST /api/tasks/batch-retry`
