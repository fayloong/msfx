# 03 — check_quantity 恢复数量对比（核心集成）

**What to build:** 数量对账脚本从"只查是否上传"恢复为"数量对比"：逐单查询平台原始单号及拆分子单，跨子单累加申报数量，与本地应有数量对比后输出三分支判定（传齐零记录 / 数量不符告警 / 未上传），无法核对时跳过；运维人员在 Web 失败记录页能看到带预期数、平台数与子单明细的"数量不符"记录。

**Blocked by:** 01, 02

**Status:** resolved
