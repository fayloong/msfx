# 05: 快照 `--all` 分支

**What to build:** `--all` 变成"初期建历史快照"的入口：把最近两年（2 年下限不变）的门店单按新口径落库，但**只写已上传记录，历史未上传的不建任务**——否则一次会灌进去约三万七千条「等待上传」，人工处理不现实、还会把待补传清单的信号淹没。跑完打印「窗口内未上传 N 张，未建任务」，让欠账是**可查的数**而不是看不见的洞。新增 `--dry-run`，跑之前先看量级。

**Blocked by:** 02（分流口径）、04（要跳过门卫）
