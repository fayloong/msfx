# 08 - 三数据页"所属企业"列与筛选 + 导出

- Type: task
- Status: ready-for-agent
- 关联：spec.md §10

## 问题

三个数据页（上传任务 / 已上传 / 失败记录）与导出 xlsx 均无企业维度。

## 实现

- 三页表格加"所属企业"列；筛选条件加"所属企业"下拉（数据来自 `config/enterprises.php` 枚举）
- 下拉按 `company` 去重；一门店多套凭据时显示 `门店名（label）`
- 导出 xlsx 加列 + 参数（`api/export.php` 与前端已计算的关键词忽略默认日期逻辑一并适配）
- 上传任务编辑弹窗**允许改"所属企业"但需二次确认**（改企业意味着重传要走另一套凭据）
- **仪表盘 4 个统计卡片本轮不按企业拆分**
- `未识别` 记录在页面上显著提示

## 验收

三页可按企业筛选、导出文件含该列；既有筛选（单号/往来单位/状态/日期）组合行为不变
